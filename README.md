# Internet Checker

Приложение для Android, предназначенное для проверки доступности интернета и выявления вероятного действия «белых списков» или VPN.

## Описание

Приложение проверяет сетевую доступность, отправляя параллельные HTTPS-запросы к трем различным группам доменов. На основе успешных и неудачных ответов программа определяет текущий режим работы сети.

## Принцип работы

Проверка выполняется методом отправки `HEAD`-запросов с таймаутом в 4 секунды. Для точности диагностики домены разделены на три группы:

*   **Группа A (Белый список):** Базовые российские ресурсы, доступные при любых ограничениях (ya.ru, gosuslugi.ru, mail.ru, rutube.ru, dzen.ru, sber.ru).
*   **Группа B (Обычный интернет):** Ресурсы вне государственных списков (habr.com, github.com, google.com, bing.com, microsoft.com, apple.com).
*   **Группа C (Заблокированные):** Ресурсы, доступ к которым ограничен на территории РФ (instagram.com, x.com, rutracker.org, discord.com, linkedin.com).

### Логика вердикта:

1.  **SYSTEM NORMAL (Норма):** Сайты групп A и B доступны, группа C (заблокированные) недоступна. Это стандартное поведение сети без обходов блокировок.
2.  **WHITELIST WARNING (Белый список):** Сайты группы A доступны, но сайты группы B не открываются. Это указывает на то, что провайдер пропускает трафик только к разрешенным ресурсам.
3.  **VPN DETECTED (Обнаружен VPN):** Доступны сайты из группы C (заблокированные). Это означает, что трафик проходит через VPN или устройство находится вне РФ.
4.  **OFFLINE (Нет сети):** Ни одна из групп сайтов не отвечает.

## Функции

*   **Асинхронная проверка:** Запросы выполняются параллельно с использованием Kotlin Coroutines, что обеспечивает быструю проверку и не блокирует интерфейс.
*   **Детальные логи:** По нажатию на кнопку «[ ЛОГИ ]» открывается окно со списком всех проверенных доменов и их статусом (`[ OK ]` или `[ FAIL ]`).
*   **Сетевой стек:** Используется библиотека OkHttp для выполнения HTTPS-запросов.

## Установка

1.  Перейдите в раздел **Releases** в правой части страницы репозитория.
2.  Скачайте актуальный файл **`Internet.Checker.apk`** из блока Assets.
3.  Откройте скачанный файл на устройстве Android.
4.  Разрешите установку из неизвестных источников, если система запросит подтверждение.

## Технологии

*   Язык программирования: Kotlin
*   Сетевые запросы: OkHttp 3
*   Многопоточность: Kotlin Coroutines
*   Разметка интерфейса: XML
